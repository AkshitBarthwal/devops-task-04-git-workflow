# Git Workflow

This project follows a simple Git workflow.

## Branches

- `main` - stable version of the project
- `dev` - development branch
- `feature` - used for new changes

## Workflow

1. Create a feature branch from `dev`.
2. Make the required changes.
3. Commit the changes with a meaningful commit message.
4. Push the feature branch to GitHub.
5. Open a Pull Request.
6. Merge the Pull Request into `dev`.
7. After testing, merge `dev` into `main`.
8. Create a Git tag for a stable release.
